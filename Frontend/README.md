# MarketNest Frontend

Angular functional prototype for the Marketplace project.

## Stack

- Angular 21
- PrimeNG 21
- PrimeIcons
- SCSS with project design tokens
- Mocked catalog data, no backend integration yet

## Prototype Scope

- Storefront home page
- Search results page
- Product detail page
- Shared shell, search bar, category card, product card, filter sidebar, and buy box components

## Development

```bash
npm install
npm start
```

Open `http://127.0.0.1:4200`.

## Validation

```bash
npm run build
npm test -- --watch=false
```
