# Marketplace Design

This directory tracks design references, prototype links, and product design decisions for the Marketplace project.

## Figma Prototype

[Marketplace - Initial Design](https://www.figma.com/design/hmR0cZYOdnD29sffBi37i6/Marketplace?node-id=0-1&t=XUxn0MKzuLcTGn1e-1)

## Current Scope

- Prototype a web marketplace.
- Use English (US) as the product language.
- Follow familiar ecommerce patterns inspired by Amazon's store structure.
- Use a distinct visual identity, avoiding Amazon's brand colors.
- Build modern, reusable UI components as the foundation for implementation.

## Figma Structure

- `00 Foundations`: colors, typography, and design principles.
- `01 Components`: reusable UI components.
- `02 Prototype`: initial desktop screens.
